# Specs

As specs de implementação devem ser criadas após a estabilização deste Product Discovery.

## Convenção sugerida

```text
specs/
  001-foundation/
    spec.md
    plan.md
    tasks.md
  002-identity/
    spec.md
    plan.md
    tasks.md
  003-writer-profile/
    spec.md
    plan.md
    tasks.md
  004-challenge-engine/
    spec.md
    plan.md
    tasks.md
  ...
```

Cada spec deve possuir:
- objetivo;
- escopo;
- requisitos;
- critérios de aceitação;
- invariantes;
- dependências;
- casos de erro;
- testes esperados.

A implementação deve obedecer às specs e ADRs aprovados.
